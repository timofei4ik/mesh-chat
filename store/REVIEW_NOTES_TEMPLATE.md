# Review notes template

MeshChat is a private messenger with direct chats, groups, channels, calls,
media, stories, optional nearby Bluetooth chat and optional location sharing.

Reviewer access:

- Server: `wss://meshchat-losa.ru/ws`
- Invite token: `[CREATE BEFORE SUBMISSION]`
- Login: `[DEDICATED REVIEW ACCOUNT]`
- Password: `[DEDICATED REVIEW PASSWORD]`

Safety navigation:

- Report message: long-press a received message, then **Report**.
- Report account: open a profile, then **Report user**.
- Report group/channel: open group/channel information, then **Report**.
- Block account: long-press a received message or use the profile action.
- Delete account: Settings, Security, **Delete account**.

Permissions are requested contextually: microphone for calls/voice messages,
camera/photos for attachments and QR scanning, location only for explicit group
sharing, and Bluetooth only for Nearby mode.
